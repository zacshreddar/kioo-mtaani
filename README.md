# KIOO MTAANI website

A one-page static site. No build step.

## Put it online with GitHub Pages (free)
1. On github.com, create a new public repository, e.g. `kioo-mtaani`.
2. Upload everything in this folder (index.html, the images folder, this README).
3. Go to Settings > Pages. Under "Build and deployment" choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/kioo-mtaani/`.

## Fill in the placeholders
Open index.html and search for the square brackets:
[WHATSAPP-CHANNEL-LINK], [INSTAGRAM-LINK], [TIKTOK-LINK], [CONTACT-EMAIL], and the [Caption] and [Describe photo] texts.

## Add photos
Put JPG files in the `images` folder with these exact names:
cover.jpg, photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg, photo5.jpg
Resize each to about 1600px wide first so the page loads fast on mobile data.

## Your own domain (optional)
Buy a domain from a registrar, then in Settings > Pages add it under "Custom domain" and follow GitHub's DNS instructions.
